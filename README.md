# Mijn Nachtvlinders — prototype v0.1

Eerste aparte app voor ButterflyCount/eBMS **moth trap** exports.

## Benodigde downloads
Upload vanuit `Moth trap downloads`:
- Download moth trap occurrences
- Download moth trap samples

Beide mogen als originele ZIP worden geüpload; uitpakken is niet nodig.

## Functies
- gebied tekenen;
- GeoJSON gebied openen/bewaren;
- automatische herkenning van occurrences en samples;
- data geografisch filteren op het gebied;
- periodefilter;
- tellingen, soorten, individuen en families;
- meest gevangen soorten;
- familieverdeling;
- maand- en jaaroverzicht;
- vangst per telling;
- heatmap van moth-trap locaties;
- nieuwe soorten door de tijd.

## GitHub / Streamlit
Upload `app.py` en `requirements.txt` naar een aparte GitHub-repository en deploy met Python 3.12.
